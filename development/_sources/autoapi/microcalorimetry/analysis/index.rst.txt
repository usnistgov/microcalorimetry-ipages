microcalorimetry.analysis
=========================

.. py:module:: microcalorimetry.analysis

.. autoapi-nested-parse::

   
   This module contains high-level routines for performing microcalorimetry analysis.

   This module should contain static functions which take in configuration objects,
   and primative types (strings, numbers) that are then used to process the data.
   Where possible, they should use math functions defined in the math module.

   These functions should be interfaceable via either a command line interface or
   a GUI where the user can only enter string-like inputs.

   These function should utilize DataModelContainers when referring to inputs that represent inputs that cant be described
   by a short string (i.e. something convenient for a command line interface). This
   enables the passing of in-memory representations
   of data via the DataModelContainers so that it isn't required to serialize the output of one function
   in order to pass it to the input of another.

.. py:function:: make_correction_factor(gc_regressor_rows: microcalorimetry.configs.CorrectionFactorModelInputs, correction_terms: int, calc_thermal_weights: bool = False, make_plots: bool = True, nominals: bool = False, cache_s11: bool = True, freq_resolution: int = 4) -> tuple[microcalorimetry.configs.GCLike, list[matplotlib.pyplot.Figure]]

   
   Calculate the correction factor for a given sensor model.

   The normal_standards and special_standards are used to generate
   the regressor matrix. All possible combinations of connect cycles
   that use the same splitter_id are used to build the regressor matrix.

   :param gcinputs: Dictionary of CorrectionFactorDataInputs.
   :type gcinputs: configs.CorrectionFactorDataInputs
   :param correction_terms: Number of terms in correction factor. Usually 1.
   :type correction_terms: int
   :param calc_thermal_weights: If true, returns thermal weighting coefficients
                                isntead of the correction factors (g_ci = wi/W0) where W0 is
                                the sensitivity of the calorimeter.
   :type calc_thermal_weights: bool, optional
   :param make_plots: Makes plots. The default is True.
   :type make_plots: bool, optional
   :param nominals: If true, propagates uncertainties.
   :type nominals: bool, optional
   :param cache_s11: If true, read ins every s-parameter file once to avoid redundant loading of files, memory intensive.
   :type cache_s11: bool, optional

   :returns: * **gc** (*RMEMeas*) -- Correction factor in RMEMeas format.
             * **figs** (*list[Figure]*) -- Matplotlib figures generated (if asked to make plots.)

   Fit sensitivity coefficients to a dcsweep measurement of a thermoelectric.

   Takes in a parsed dc measurement and generates sensitivity coefficients.

   :param parsed_dcsweep: Steps parsed from sensitivity measurement. The first field
                          is the applied voltage, the second field is the applied current,
                          and the last field is the measure thermopile voltage.
   :type parsed_dcsweep: microcalorimetry.configs.ParsedDCSweep
   :param thermometer_corrected: Use a thermometer corrected model. Requires a thermometer
                                 voltage and current to be present in the parsed DC sweep. The default
                                 is False.
   :type thermometer_corrected: bool, optional
   :param constrain_zero: Constrains the fit to zero, only applies to non-thermometer
                          corrected models. The default is False.
   :type constrain_zero: bool, optional
   :param p_of_e: Fit power as a function of thermopile voltage if True. If False,
                  fits thermopile voltage as a function of power. Only applies to non
                  thermometer corrected models. The default is False.
   :type p_of_e: bool, optional
   :param deg: Fit degrees of polynomial for non thermometer corrected models.
               Only applies to non thermometer corrected models. The default is 2.
   :type deg: int, optional
   :param min_p: The minimum power value to include in the fit. Values below this will be included
                 as part of the residuals. The default is 0.001 (1 mW).
   :type min_p: float, optional
   :param make_plots: Output plots if True.
   :type make_plots: bool, optional

   :returns: * **sensitivity** (*RMEMeas[arrays.KDCTemInd | arrays.KDCTempDep]*) -- Sensitivity coefficients
             * **figures** (*list[plt.Figure]*) -- List of figures generated (empty if not made). Fit and residuals.

.. py:function:: make_classical_eta_unc_model(frequency: numpy.array, model: microcalorimetry.configs.PythonFunction, u_type: str, correlate_frequencies: bool = True, make_plots: bool = True) -> tuple[rmellipse.uobjects.RMEMeas[microcalorimetry.arrays.Eta], matplotlib.pyplot.Figure]

   
   Generate a classical uncertainty model for an eta measurement.

   uA_model and uB_model are python functions that take in a frequency
   list and output a standard uncertainty (Type A and B respectively).

   This model can be used to apply uncertainties to an eta calculate
   after it has been calculated. Is is zero nominal, so uncertainties are
   added to an eta measurement by simply adding it to to an effective
   efficiency measurement.

   Uncertainties are assumed to be independent across frequency.

   :param frequency: Frequency in GHz.
   :type frequency: np.array
   :param model: Python function that outputs type B uncertainty.
   :type model: configs.PythonFunction
   :param u_type: Type of uncertainty (A or B)
   :type u_type: str
   :param correlate_frequencies: Treat uncertainties as correlated if True. The default is True.
   :type correlate_frequencies: bool, optional
   :param make_plots: If True, make plots.
   :type make_plots: bool, optional

   :returns: * **eta_unc** (*RMEMeas[arrays.Eta]*) -- Eta configuration object with zero nominal and uncertainties
               derived from uA_model and uB_model.
             * **fig** (*plt.Figure | None*) -- Matplotlib figure object generated.

.. py:function:: dc_lead_correction(eta: microcalorimetry.configs.EtaLike, R_lead: float, R_bolo: float, R_lead_max: float = 0.14) -> tuple[rmellipse.uobjects.RMEMeas[microcalorimetry.arrays.Eta]]

   
   Applies a dc lead correction.

   Corrects for heat lost between the dc connector and the
   4-wire connection of a resistor inside the sensor.
   See ERROR IN CALORIMETRIC EFFECTIVE EFFICIENCY MEASUREMENTS DUE TO DC LOSSES, T.P
   Crowley and B.F. Riddle for more details.

   :param eta: Path to an effective efficiency measurement to apply the correction to.
   :type eta: configs.EtaLike
   :param R_lead: Sum of resistance for Force and Sense leads of sensor.
   :type R_lead: float
   :param R_bolo: Bolometer resistance, usually 200 ohms for bolometer sensors.
   :type R_bolo: float
   :param R_lead_max: This is the maximum allowed resistance for force and sense leads of the sensor.
                      Uncertainty is only applied for R_lead > R_lead_max, and only excess uncertainty
                      is applied. It is assumed uncertainty
                      associated with lead resitances less than or equal to R_lead_max have
                      already been accounted for. Set to zero to count all the uncertainty associated
                      with your lead resistance. The default value is 0.14 Ohms, which is the typical
                      allowable value for CN mounts in NIST's Type N microcalorimeter.
   :type R_lead_max: float

   :returns: **eta** -- Corrected eta value
   :rtype: RMEMeas[arrays.Eta]
