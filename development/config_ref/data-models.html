MeasLike Objects¶

This page contains config Schema’s used to defin MeasLike objects as part of configuration files. A MeasLike is something that could be a measurmeent - either a file path that contains the measurment data or the in memory data itself.

Meas Like Objects¶

Meas Like objects represent something that could be an in memory data set or a file containing a data set.

examples

path/to/data.file

path/to/data.hdf5/path/to/group

DCSweepLike¶

File, HDF5Group, or in memory representation of a DCSweep dataset.

examples

path/to/data.hdf5/path/to/sweep

additionalProperties

False

RFSweepLike¶

HDF5Group of an RFSweep dataset.

examples

path/to/data.hdf5/path/to/sweep

additionalProperties

False

KDCLike¶

File, HDF5Group, or in memory representation of a ThermoelectricFitCoefficients.

examples

path/to/data.hdf5/path/to/coeffs

additionalProperties

False

S11Like¶

File, HDF5Group, or in memory representation of an S11 dataset. Could be a DUT file or an HDF5 file.

examples

s11_file.dut

data.h5/s11_group

additionalProperties

False

EtaLike¶

File, HDF5Group, or in memory representation of effective efficiency.

examples

eta_file.eff

data.h5/eff_group

additionalProperties

False

GCLike¶

File, HDF5Group, or in memory representaion of a microcalorimeter correction factor.

examples

data.h5/gc_group

additionalProperties

False
